# Trout Master: онлайн-результати змагань

Сторінка показує результати з Google Таблиці й сама перевіряє оновлення кожні 20 секунд. Глядачам не треба нічого перезавантажувати.

```
Google Таблиця  →  Apps Script (віддає JSON)  →  сайт на GitHub Pages
```

## Що в репозиторії

| Файл | Навіщо |
|---|---|
| `index.html`, `assets/` | Сам сайт: розмітка, стилі, скрипт, шрифт Inter, логотип |
| `config.js` | Налаштування сайту: адреса Apps Script і частота оновлення |
| `demo.json` | Демо-дані. Сайт показує їх, поки в `config.js` не вставлено адресу Apps Script |
| `apps-script/Code.gs` | Код для Apps Script, який читає таблицю |

## Яку частину таблиці показує сайт

Сайт бере дані з аркуша **Results** і показує дві вкладки:

| Вкладка | Діапазон |
|---|---|
| Результат | `AK1:AO` |
| Тури | `A1:AI` |

- Перші два рядки кожного діапазону є заголовками. Об'єднані клітинки першого рядка («Тур 1», «Підсумок», «Результати») стають групами колонок.
- Рядки беруться до останнього заповненого. Рядки без імені учасника пропускаються.
- Значення **В**, **П**, **РН**, **БН** у турах показуються кольоровими мітками.
- Інші частини аркуша (командні таблиці) та аркуш «Учасники» на сайт не потрапляють.

Якщо зміниться макет таблиці, діапазони правляться на початку `Code.gs` у блоці `VIEWS`. Після цього потрібно оновити розгортання (див. нижче).

## 1. Налаштувати Apps Script (один раз, близько 5 хвилин)

1. Відкрийте [script.google.com](https://script.google.com) і натисніть **«Новий проєкт»**. Назвіть його, наприклад, «Trout Master API».
2. Видаліть усе з файлу `Code.gs` і вставте вміст файлу `apps-script/Code.gs` з цього репозиторію. Збережіть (Cmd+S).
3. Зліва натисніть ⚙ **«Налаштування проєкту»** → **«Властивості скрипту»** → **«Додати властивість скрипту»** і додайте три властивості:

   | Властивість | Значення (приклад) |
   |---|---|
   | `SPREADSHEET_ID` | посилання на таблицю раунду |
   | `EVENT_TITLE` | `Round 1` |
   | `EVENT_SUBTITLE` | `21 листопада • Плугів • Krychevychi Area Fishing` |

   Натисніть **«Зберегти властивості скрипту»**.
4. Поверніться в **«Редактор»**, угорі у списку функцій виберіть `testConnection` і натисніть **«Виконати»**. Google попросить дозвіл: **«Переглянути дозволи»** → ваш акаунт → **«Розширені»** → **«Перейти до Trout Master API (небезпечно)»** → **«Дозволити»**. Попередження стандартне для власних скриптів. У журналі має з'явитися кількість рядків для вкладок «Результат» і «Тури».
5. **«Розгорнути»** → **«Нове розгортання»** → ⚙ біля «Виберіть тип» → **«Веб-застосунок»**.
   - Виконувати від імені: **Я**
   - Хто має доступ: **Усі**
   - **«Розгорнути»** і скопіюйте **URL веб-застосунку** (закінчується на `/exec`).
6. Відкрийте цей URL у браузері. Має з'явитися текст, що починається з `{"ok":true`.
7. Вставте URL у `config.js` у поле `API_URL` (на GitHub: відкрити файл → ✏️ → вставити → Commit changes). За хвилину сайт почне показувати живі дані.

## 2. Новий раунд

У властивостях скрипту змініть `SPREADSHEET_ID` на посилання нової таблиці, а також `EVENT_TITLE` і `EVENT_SUBTITLE`. Більше нічого робити не треба: ні перерозгортати скрипт, ні змінювати сайт. Сайт підхопить зміни протягом пів хвилини.

Робіть таблицю нового раунду копією попередньої (Файл → Створити копію), щоб аркуш і діапазони лишилися ті самі.

## 3. Що бачать глядачі

- Вкладки «Результат» і «Тури».
- Таблиці із зеброю. Широка таблиця турів гортається вбік, а колонки «#» і «Учасник» лишаються на місці.
- Тап по рядку виділяє учасника. Виділення зберігається в браузері глядача й діє на обох вкладках.
- Після кожного оновлення стрілки ▲ і ▼ показують, хто скільки місць виграв чи втратив, а змінені клітинки на мить підсвічуються.
- Угорі видно статус «Оновлено о 14:32», тобто час останньої зміни даних. Якщо зв'язок зник, сторінка показує останні отримані дані й попередження.

## Якщо змінюєте код Apps Script

**«Розгорнути»** → **«Керувати розгортаннями»** → ✏️ → Версія: **«Нова версія»** → **«Розгорнути»**. Адреса `/exec` залишиться та сама. Якщо натиснути «Нове розгортання», адреса зміниться і її доведеться оновити в `config.js`.

## Ліміти

Готова відповідь кешується на 10 секунд, тому таблиця читається не частіше разу на 10 секунд, хоч би скільки людей дивилися сайт. Для кількох десятків глядачів квот Apps Script вистачає з великим запасом.
