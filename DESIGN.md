# TROUT MASTER: дизайн-хендоф для наступних чатів

Цей документ для Claude (і для будь-кого, хто продовжить роботу). Тут зібрано, як влаштований сайт, яка в нього дизайн-мова, як вносити зміни й перевіряти їх. Що робить сайт для організатора й глядачів, описано в `README.md`.

## Коротко про проєкт

- **Сайт:** https://troutmaster.app/ (домен у Cloudflare, DNS only → GitHub Pages; стара адреса github.io перенаправляє сюди). Це vanilla JS без фреймворків; збирання — лише склеювання модулів `src/` скриптом `tools/build.js`. Хоститься на GitHub Pages з гілки `main`.
- **Telegram Mini App:** @troutmasterua_bot (`t.me/troutmasterua_bot?startapp`). Це той самий сайт усередині Telegram.
- **Дані:** Google Таблиця → Apps Script (`apps-script/Code.gs`) → JSON → сайт опитує його кожні 15 с.
  - Таблиця раунду: `13wvgmiuQeCl6ap4QmScSdf1dR0_wUuljV9-1-GggLdk`, аркуш «Сайт».
- **Партнер:** FISH.ME.FISH, `t.me/fishmefish_japan`, логотип у `assets/partners/fishmefish.svg`.
- **Власник:** Андрій Тесля. Пише українською й любить преміальний, вилизаний дизайн.

## Як працювати з Андрієм

- Відповідати українською, коротко, без зайвої технічки.
- Якщо задача неоднозначна, спершу запитати. Якщо зрозуміла, робити одразу.
- Після змін закомітити, запушити і **надіслати коротке відео або скрін результату**. Андрій це дуже цінує.
- Він тестує на iPhone у Telegram і на Mac у браузері. Те, що не відтворюється в Chromium (overscroll iOS, хмара Telegram), просити перевірити на пристрої.
- Безпека:
  - `BOT_TOKEN` лишається тільки у властивостях скрипта, ніколи не просити й не показувати його.
  - Телефони й Telegram ID не потрапляють на сайт.
  - Email Андрія використовувати лише для ідентифікації.

## Деплой

1. Змінити файли в `src/js` / `src/css` (і `index.html`, `assets/i18n.js` — їх не збирають).
2. Зібрати: `node tools/build.js`.
3. Прогнати тести: `node tests/smoke.js` — усе має бути ✓. Нова фіча — новий сценарій у `tests/smoke.js`.
4. Підняти версію в `index.html`: `sed -i 's/20261108p/20261108q/g' index.html`. Формат: дата плюс літера, і літера щоразу нова.
5. Закомітити зрозумілим повідомленням українською й запушити в `main`. Pages оновиться за хвилину-дві.
   - У GitHub Actions червоний «!» на старих прогонах означає скасовані, перекриті новими. Це не помилки.
6. Зміни в `Code.gs`:
   - Андрій сам вставляє новий код у редактор Apps Script.
   - Нове розгортання потрібне лише тоді, коли змінився `doGet`/`doPost`. Тоді: «Керувати розгортаннями» → «Нова версія».
   - Тригери й `publish_` працюють і без розгортання.

## Перевірка (Playwright)

Основні сценарії вже покриті в `tests/smoke.js` — запускати після кожної зміни. Для скрінів і відео Андрію — та сама схема окремим скриптом.
Chromium і Playwright уже встановлені. Схема тесту:
- піднімаємо локальний статичний сервер на корінь репозиторію;
- мокаємо `https://script.google.com/**` JSON-пейлоадом;
- робимо скріни або відео (`recordVideo`);
- кадри витягуємо через ffmpeg.

```js
const {chromium}=require('playwright');const fs=require('fs'),http=require('http'),path=require('path');
const ROOT='/home/claude/trout-master-results';
const srv=http.createServer((q,r)=>{let p=path.join(ROOT,decodeURIComponent(q.url.split('?')[0]));if(p.endsWith('/'))p+='index.html';
  fs.readFile(p,(e,d)=>{if(e){r.writeHead(404);return r.end();}r.writeHead(200,{'Content-Type':{'.html':'text/html','.js':'text/javascript','.css':'text/css','.svg':'image/svg+xml','.webp':'image/webp','.json':'application/json'}[path.extname(p)]||'application/octet-stream'});r.end(d);});}).listen(8176);
(async()=>{const b=await chromium.launch();
  const ctx=await b.newContext({viewport:{width:1440,height:860},locale:'uk-UA',recordVideo:{dir:'vid',size:{width:1440,height:860}}});
  const p=await ctx.newPage();
  await p.addInitScript(()=>{try{localStorage.setItem('tm:lang','uk')}catch(e){}});   // без цього headless відкриється англійською
  await p.route('https://script.google.com/**',r=>r.fulfill({status:200,contentType:'application/json',body:fs.readFileSync('payload.json','utf8')}));
  await p.goto('http://localhost:8176/');await p.waitForTimeout(2500);
  /* дії + p.screenshot(...) */
  await ctx.close();await b.close();srv.close();})();
```

- **Пейлоад:** найпростіше взяти живий через `curl` з адреси `API_URL` у `config.js` і правити під сценарій: закінчений турнір, 1 тур, відкрита реєстрація, 14 (6, 8) сектори.
- **Telegram-режим:** у моку `telegram-web-app.js` підкласти заглушку `window.Telegram.WebApp`.
- **Мобайл:** viewport 390×844, `isMobile: true`, `hasTouch: true`.
- **Демо Андрію:** `ffmpeg -i in.webm -c:v libx264 -preset veryfast -crf 23 -pix_fmt yuv420p out.mp4`, потім SendUserFile.

## Екрани й компоненти

### Шапка (навбар)

- Логотип — посилання на головну (`#logoHome`): з будь-якого екрана `goList()`, на головній — плавно вгору. Логотип і топ-навігація «Результати / Статистика» з повзунком.
- Праворуч:
  - статус «Оновлено о 14:32» (слово «Оновлено» ховається вужче 420px);
  - кнопка «Оновити» (комп);
  - перемикач «УКР | ENG».

### Блок турніру (hero)

- Назва, дата й місце, пігулка FISH.ME.FISH (комп), кнопка «Telegram-чат» у градієнті Telegram (`#chatWeb`, комп; в апці — `openTelegramLink`), «Статистика».
- Плитки KPI:
  - Тур X з N;
  - Лідер / Переможець;
  - Усього риби (зі спарклайном, якщо є; третім рядком «Найуловистіший сектор: N» з `tournamentSectors()`; спарклайн 30px, щоб підпис і число стояли на одній висоті з сусідніми плитками);
  - під час реєстрації: «Вільно N місць», таймер (на компі із секундами).
- Коли реєстрацію закрито, плитки показують «Реєстрація — Закрита» і «До старту — N днів».

### Таблиця (комп)

- Біла картка `.bcard`, у ній `.btools`: заголовок, легенда, сегмент «Підсумок / По турах», пошук із хрестиком.
- **При прокручуванні прилипають:**
  - `.btools` (top 0);
  - рядок назв колонок `.rk-head`;
  - у «По турах» — копія шапки `.tgrid-hd`, бо справжня сидить у горизонтальному скролі і її `scrollLeft` синхронізується.
  - Висота `.btools` передається в CSS-змінній `--bt-h` (ResizeObserver): дробова `getBoundingClientRect().height − 1px` — з округленим `offsetHeight` між панеллю й рядком колонок була щілина.
  - **Важливо:** `.bcard` має `overflow: clip`, не `hidden`, інакше sticky не працює.
- **Вибраний учасник:** чорна плаваюча таблетка `#selbar` по центру знизу. У ній місце, «Вибрано в таблиці», ім'я · бали, зелена «Картка учасника», ✕. У режимі «Список учасників» те саме, але в кружечку номер, «Вибрано в списку» і без балів (`#selLbl`).
  - Елемент перенесено в `body`, щоб його не перекривав знімок View Transition.
  - Поки таблетка відкрита, `html.sel-on` додає запас знизу.

### Мобайл

- Таблиця — «аркуш». Шапки таблиць прилипають у Telegram під панеллю.
- Внизу фіксована `.regbar`: «Зареєструватися», «Статистика» або «Картка». Над нею левітує партнер.
- **Над футером** (`html.foot-in`, ставить скрипт у `80-telegram.js` за положенням футера відносно нижньої панелі): світла підкладка `.regbar` / `.pc-storybar` плавно стає чорною (`::before` з opacity), чорна кнопка — білою, тіні зникають. Місце під нижньою кнопкою — у `padding-bottom` футера, а не `.main` / `.pc-sheet`.
- У результатах під іменем лише «12В · 1РН · 0БН · 1П» (кольорові смужки форми на телефоні прибрано).
- У списку учасників тим, хто оплатив (`payload.paid` — імена з галочкою «Оплата»), праворуч значок `assets/icons/paid.webp`.
- Банер `#nbar` (requestWriteAccess) світло-зелений, лише в Telegram, поки бот не може писати. Глядачам: «Результати — у Telegram» / «Отримувати результати», хрестик ховає на 14 днів. Зареєстрованим (`state.myNames` з «Хто я?»): «Ви в списку учасників — увімкніть сповіщення…» / «Увімкнути сповіщення», після хрестика чи «Ні» повертається через 2 дні (`tm:nbarRegHideUntil`).

### Картка учасника

- **Hero:** фото або ініціали в кружечку `.pc-ava--ini`, місце-бейдж.
- **Цифри:** «докручуються».
- **Блоки:** тури, графіки улову й місця, рекорди, особисті зустрічі.
- **Перехід:** до попереднього/наступного учасника.
- **Поділитися карткою:** у Telegram `t.me/troutmasterua_bot?startapp=p9`, у браузері `https://troutmaster.app/#p9` (`shareUrl(n)`). `#p9` прибирається з адреси одразу (`takeHashPlayer()` ловить і вставку в уже відкриту вкладку), картка відкривається поверх запису «список» в історії.
- **«Поділитися в сторіс»:** картинка на canvas (внизу «РЕЗУЛЬТАТИ Й СТАТИСТИКА / troutmaster.app»). Перемикач «Сторіс 9:16 / Допис 4:3» з повзунком `segSlide`. На вебі кнопки 44px. «Поділитися» передає ще й підпис з посиланням (`storyCaption`: «Ім'я — 5-те місце, 21 бал на TROUT MASTER 🎣 / Статистика: url»); Instagram-сторіс його ігнорують.
- **Порівняння:** під «рахунком» показників примітка «Перевага в показниках не означає вищого місця…», а якщо попереду за показниками нижчий у таблиці — «Тому вище в таблиці — …».

### Порівняння учасників («Двобій», `src/js/57-compare.js`, `src/css/97-compare.css`)

- **Вибір:** у результатах (не в списку учасників і лише коли є зіграні тури, `canCompare()`) тап по рядку — перший (`state.selected`, як раніше), тап по іншому — другий (`state.cmpKey`, не зберігається), тап по третьому замінює другого. Зняти першого — другий стає першим. `selectOnly()` скидає другого. Підсвітка рядків — `isSel(key)`.
- **Кнопка:** на телефоні `#cardOpen` стає «Порівняти» (`.is-cmp`, іконка `.ic-cmp`); на компі таблетка `#selbar.is-cmp`: два кружечки місць внахлест (`#selPlace`, `#selPlace2`), «Порівняння», «А vs Б», «Порівняти».
- **Екран:** живе в контейнері картки (`state.cmpOpen`, `renderCard()` → `renderCompare()`), тож «Назад», Telegram BackButton і свайп працюють як у картки; після «Назад» обидва лишаються виділеними.
- **Вміст:** шапка — двоє з фото/ініціалами, місцем і № та «VS»; «рахунок» кращих показників (напр. 8 : 2) і різниця в балах та улові; «Особисті зустрічі», якщо за жеребкуванням вони суперники (зазвичай один тур: улов кожного по боках, тур і сектор по центру, переможець зеленим; нічия підписана; майбутня — «ще попереду»; від 2 зіграних — у заголовку підсумок перемог між собою); блоки «Основне» (бали, В, РН, БН, П, улов, проти суперників — 4 плитки картки) і «Статистика» (відсоток перемог, середній улов, частка риби, найкращий тур, серія, сектори). Нічиї й сектори — довідково, без переможця. Кращий — зелений із крапкою, смужка-шкала ділиться пропорційно, виростає від центру. Цифри «докручуються».

## Мови (i18n.js)

- **Пайплайн `tr()`:**
  1. `EXACT` — точні фрази;
  2. `RULES` — регекспи з числами, місяцями, кодами В/РН/БН/П → W/FD/ND/L;
  3. `PHRASES` — частини речень;
  4. пословний `EXACT`;
  5. транслітерація (КМУ № 55: «Тесля Андрій» → «Teslia Andrii»).
- **Підміна в DOM:** MutationObserver перекладає DOM на льоту. Оригінали лежать у WeakMap, тож повернення до УКР працює без перезавантаження.
- **Вибір мови** зберігається в `localStorage` під ключем `tm:lang` і в Telegram CloudStorage під ключем `tm_lang`.
- **Мова за замовчуванням:** англійська лише якщо мова Telegram або браузера `en*`.
- **Нові тексти в app.js:** додавати переклад у `EXACT` або `RULES`. Неперекладені слова видно в `TM_I18N.misses`.
- **Назва турніру:** скрипт перекладає її через `LanguageApp.translate` (кеш у ScriptProperties) і віддає як `event.titleEn` / `subtitleEn`.

## Apps Script: що варто пам'ятати

- **Аркуш «Сайт»:** публікація B3, режим B5, реєстрація B8–B12, сектори B13 (текст, без валідації), вартість участі B14 (текст → `payload.fee`, у формі реєстрації під кнопкою), діапазони B17:B19, нижче блок розсилки.
- **Учасники:** C — галочка «Оплата» (C1 «Оплата: N/M»; галочка додається при реєстрації; на сайті — значок біля імені), D — сума, грн (D1 «Зібрано: N грн»; лише для організатора). Колонка C раніше була об'єднаною клітинкою C1:C150 — `setupPaidColumn_` її роз'єднує. Тип перевірки — `SpreadsheetApp.DataValidationCriteria.CHECKBOX`.
- **Особисті результати в Telegram** (блок на «Сайті» під табличкою картинок, `setupResults_`): Фото / Дія («Надіслати тест собі», «Надіслати учасникам», «…ще раз») / Стан. Текст складає `resText_`: місце й ▲▼ (місця зберігаються при кожній публікації результатів у `res:places:<тур>`; очищаються, коли режим знову «Список учасників»), бали · перемоги · риби, відрив до місця вище, останні 5 турів, «Попереду ще N турів» / «Дякуємо за участь». Захист від повтору — `res:sent`. Після публікації в B4 — підказка «📨 можна надіслати…».
- **Розсилка:**
  - «Кому»: Собі / Учасникам / У чат / Усім.
  - Заповнена «Кнопка» — **єдина** кнопка.
  - «Моя картка в TM APP» лише з фото «Проміжні результати» / «Підсумкові результати».
  - «Без фото» — у списку картинок.
  - Статуси причин недоставки: `bcWhy_`.
- **Telegram ID:** перевіряється підписом через `BOT_TOKEN`.
- **Журнали:** «Відвідування» і «Журнал візитів» ведуть статистику.
- **Кліки по партнерах:** `a[data-partner]` → `trackPartner()` шле `{action:'pclick', partner, dev, vid, tg}` → `partnerClick_` пише в прихований «Журнал кліків», `ensurePartnerBlock_` додає блок партнера на «Партнери» (формули COUNTIFS/COUNTUNIQUEIFS, конверсія — від унікальних із «Журналу візитів»). Новий action у `doPost` — після зміни потрібна «Нова версія» розгортання.

## Відомі пастки

- Однаковий `hash` пейлоаду блокує оновлення на сайті. У тестах FLIP міняти і дані, і `hash`.
- Позицію `.seg-ind` міряти тільки після `has-seg` (position: relative).
- `sed` по CSS: у файлі немає відступів у багатьох правилах, тож патерни треба якорити точно. Для довгих замін надійніше Python із `assert s.count(old)==1`.
- У `fmtInt` вузький пробіл U+2009 як роздільник тисяч.
- Нові фіксовані елементи на компі можуть опинитися під знімком View Transition. Тоді або переносити їх у `body`, або давати їм власний `view-transition-name`.
- На iOS overscroll і нативну «кришку» Telegram у Chromium не перевірити.
